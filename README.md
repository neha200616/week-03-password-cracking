# Week 03 – Password Cracking

**Cybersecurity & Ethical Hacking | Practical Project**

## About This Repository

This repository documents my Week 03 hands-on practical work in Cybersecurity and Ethical Hacking.

The projects focus on password security, PDF hash extraction, password recovery techniques, and understanding the importance of strong passwords.

## Projects

### Project 01: Password Cracking with John the Ripper (JTR)

**Tools Used:**
- John the Ripper
- Johnny GUI
- PDF Hash Extractor

**Objectives:**
- Understand password hashing.
- Extract password hashes from protected PDF files.
- Perform password recovery using John the Ripper.
- Learn the importance of password security.

**Project Folder:** `Project-01-John-The-Ripper/`

### Project 02: Password Cracking with Networkwalks Tools

**Tools Used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web Browser

**Objectives:**
- Extract PDF password hashes.
- Understand hash-based password recovery.
- Test password strength using an online tool.
- Understand cybersecurity risks associated with weak passwords.

**Project Folder:** `Project-02-Networkwalks/`

## Skills & Concepts Learned

- Cybersecurity fundamentals
- Ethical hacking fundamentals
- Password cracking techniques
- Hash extraction and analysis
- John the Ripper basics
- Password security assessment
- Practical security testing

## Learning Outcome

Through these practical exercises, I learned how password recovery tools work, how weak passwords can be exposed, and why strong, unique passwords are essential for protecting sensitive information.

## Disclaimer

These exercises were conducted for educational purposes in an authorized lab environment. Password testing should only be performed on files and systems for which permission has been granted.
